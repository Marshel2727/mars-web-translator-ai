Parameter Model AI

Atur parameter inferensi Ollama untuk menyesuaikan antara kecepatan dan kualitas terjemahan. Untuk subtitle video atau teks pendek, kecilkan num_ctx dan num_predict agar jauh lebih cepat.

2048 token
Jumlah token konteks yang diproses model. Lebih kecil = lebih cepat.
128
Batas panjang output model. Untuk subtitle, 64–128 sudah cukup.
0.00
Kreativitas model. 0 = deterministik & konsisten (direkomendasikan untuk terjemahan).
0.80
Nucleus sampling. Nilai lebih rendah = output lebih terfokus.
Berapa lama model tetap di VRAM setelah digunakan. Lebih lama = request berikutnya lebih cepat.
